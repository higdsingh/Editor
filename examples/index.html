🚀 AI Grammar & Content Plugin

Web-based office suite plugin with offline support. Check grammar, get synonyms, generate content, and more!

📖 How to Use

  1. Type or paste text in the editor below
  2. The plugin panel will appear on the bottom right
  3. Use the tabs to check grammar, find synonyms, or generate content
  4. Download offline data for use without internet connection
  5. Configure AI models and settings in the Settings tab
💡 Features: Grammar checking • Spelling detection • Synonym suggestions • Content generation • Article writing • Offline mode • Multiple AI models (OpenAI, Gemini, Claude)
